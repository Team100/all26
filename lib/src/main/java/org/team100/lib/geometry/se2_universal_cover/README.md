# Universal Cover of SE(2)

In SE(2), rotation is periodic: zero and 2*pi are the same.
SE(2) is homeomorphic to R^2 x S^1.

Sometimes, we want to represent geometry which is not periodic,
for example turning more than a full circle, i.e. "winding."

For this purpose we use the Universal Cover of SE(2), which
is homeomorphic to R^2 x R^1.  Note that it is not isomorphic,
because the Universal Cover of SE(2) (like SE(2) itself) is
non-abelian, i.e. not commutative, whereas R3 is.
